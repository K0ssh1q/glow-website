GLOW LAUNCHER

Privacy policy.

This policy describes the current development version of Glow Launcher and this website. Glow is an independent project.

Website

This static website has no contact forms, account system, or analytics code added by Glow. GitHub Pages serves the site and may process connection information such as IP addresses in its service logs. The site loads fonts from Google Fonts, which receives your connection information when the fonts are requested.

Microsoft accounts

Glow opens Microsoft sign-in in your browser or uses a Microsoft device code. Your Microsoft password is entered with Microsoft, not in Glow. The launcher exchanges authorization data with Microsoft, Xbox and Minecraft Services to retrieve a Minecraft profile and check game ownership. The native login flow is awaiting authorization and real-world validation.

On Windows, the launcher uses the operating system credential store for saved authentication credentials. Minecraft requires an access token at launch. Mods run within the game process and may have access to data available to the game. The integrated In-Game Account Switcher manages its own account storage and authorization.

Local data

Glow stores instance settings, game files, worlds, mods, caches, profile information and diagnostic logs on your computer. Game logs may contain information provided by the game or installed mods. Review logs before sharing them. Removing an account in Glow and removing local game data are separate actions.

Services contacted

Depending on the features you use, Glow connects to Microsoft and Minecraft services for authentication and game metadata, Fabric for loader metadata, Modrinth for content, and Java runtime providers for runtime downloads. These providers receive requests needed to provide their services and have their own privacy policies.

The experimental Glow AI feature can use a local model. If you configure an external compatible service and confirm a request, the selected source content is sent to that service.

Development status

Glow is under development. Features and data handling may change as the project is tested and released. This policy will be updated as the application changes.

Third-party services

Learn more in the GitHub Privacy Statement, Google Privacy Policy, Microsoft Privacy Statement, and Modrinth Privacy Policy.
